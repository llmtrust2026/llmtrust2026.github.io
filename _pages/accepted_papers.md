# Accepted Papers

Accepted papers will be published in the **ACM Digital Library** as part of the **FSE 2026 Companion Proceedings**.

We are pleased to announce the following accepted papers for **LLMTrust 2026**:

- **Latent Security Threats in Modern Software Code Logs**  
  **Authors:** Rrezarta Krasniqi, Abanti Chakraborty Shruti (University of North Carolina at Charlotte)

- **LLM-Based Grid-World Path Planning With Probabilistic Model Checking**  
  **Authors:** Asher Tempest Arya, Aren A. Balbikian, Sophia Jit, Marsha Chechik (University of Toronto)

- **Fairness in Multi-Agent Systems for Software Engineering: An SDLC-Oriented Rapid Review**  
  **Authors:** Corey Yang-Smith, Ronnie de Souza Santos, Ahmad Abdellatif (University of Calgary)

- **Tone Perturbations as Trust Probes: Evaluating Behavioral Stability of LLMs in Software Engineering Tasks**  
  **Authors:** Mohamad Kassab (Boston University); Youssab Ibrahim (New York University Abu Dhabi)

- **A Differential Fuzzing-Based Evaluation of Functional Equivalence in LLM-Generated Code Refactorings**  
  **Authors:** Simantika Bhattacharjee Dristi, Matthew B. Dwyer (University of Virginia)

- **LLMSafeGuard: A Training-Free Framework for Safeguarding LLM Decoding via Context-Wise Similarity Validation**  
  **Authors:** Ximing Dong (Centre for Software Excellence, Huawei Canada); Shaowei Wang (University of Manitoba); Dayi Lin (Centre for Software Excellence, Huawei Canada); Ahmed E. Hassan (Queen's University)
